# Телескопная — лабораторная работа № 5

Гостевой SPA для просмотра телескопов. Стек: React, TypeScript, Vite, React Router и React-Bootstrap.

## Запуск

Из корня фронтенд-репозитория:

```powershell
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --port 3000 --strictPort
```

Открой `http://127.0.0.1:3000`. По умолчанию приложение использует только локальные mock-данные. Для скриншотов открой вкладку Network и выбери **Fetch/XHR**: запросов к API не будет. Изображения, видео и шрифты также загружаются из фронтенда. Команда `npm.cmd run build` проверяет TypeScript и собирает приложение в `dist/`.

## Страницы

| Страница | Поля и действия |
| --- | --- |
| Плитка — `/telescope-tile` | Два ползунка задают минимальную и максимальную широту от −90° до 90°. «Применить» фильтрует каталог. Карточка показывает фото, название и число лайков. «Подробнее» открывает её в ленте. |
| Лента — `/telescope-feed` | Видеокарточка показывает название, описание, координаты и число лайков. «Ещё» раскрывает описание, стрелка открывает следующую карточку. Без `id` открывается первая карточка. |

В нижней панели доступны «Лента» и «Плитка». «Добавление» и «Вход» отключены. Лайки в гостевом режиме отображаются без возможности изменить их.

## Mock и компоненты

- `src/modules/mock.ts` — коллекция телескопов. У PowerSeeker 80AZS пустые поля фото и видео: на нём можно показать обе локальные заглушки.
- `LatitudeFilter` получает `range`, `onChange` и `onApply` через props. Плитка хранит в `useState` текущие и применённые границы отдельно.
- `useEffect` загружает данные при изменении применённого фильтра или параметров ленты. При смене параметров и уходе со страницы эффект отменяет предыдущий запрос.
- `useSearchParams` читает `id` и `next` для ленты. `useState` в карточке ленты управляет раскрытием описания.

## Подключение готового Go API

Для отдельной проверки интеграции запусти Go-бэкенд из соседнего репозитория `exoplanet-mass-definition-backend` и создай `.env.local` в корне фронтенда:

```dotenv
VITE_DATA_SOURCE=api
VITE_API_TARGET=http://localhost:80
```

Перезапусти Vite. Плитка будет вызывать `GET /api/telescopes?min=…&max=…`, лента — `GET /api/telescopes/feed` с параметрами `id` и `next` при необходимости. Прокси Vite сохраняет префикс `/api`. Для показа ЛР5 удали `VITE_DATA_SOURCE=api` и перезапусти Vite: вернётся режим mock.
