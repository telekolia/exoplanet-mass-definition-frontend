# Телескопная — лабораторная работа № 6

SPA на React и TypeScript: гостевой просмотр телескопов, вход по JWT, создание и публикация черновика, удаление своих карточек и лайки. Используются Vite, React-Bootstrap, Redux Toolkit, redux-thunk и Axios.

## Запуск

В корне фронтенд-репозитория:

```powershell
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --port 3000 --strictPort
```

Открыть `http://127.0.0.1:3000`. Готовый Go-бэкенд запускается отдельно на порту **8000**. Для входа и действий пользователя также должны работать PostgreSQL, Redis и MinIO.

Vite проксирует `/api` на `http://localhost:8000`, сохраняя префикс. Для S3 есть отдельный маршрут: `/s3` → `http://localhost:9000` с удалением префикса `/s3`. Ссылки MinIO из ответа API преобразуются в адреса этого прокси. Настройки для других адресов можно задать в `.env.local` по образцу `.env.example`; после изменения нужно перезапустить Vite. В `VITE_S3_TARGET` указывается адрес S3 API без имени бакета.

Переменная `VITE_DATA_SOURCE` из ЛР5 больше не используется: приложение всегда сначала обращается к API. Только для гостя при сетевой ошибке, тайм-ауте или ответе сервера 5xx показывается отфильтрованная коллекция mock с уведомлением. Корректный пустой список и ошибки 400/401/403/404 не заменяются демонстрационными карточками. После входа подмена данными mock запрещена.

## Страницы

| Страница | Гость | После входа |
| --- | --- | --- |
| Плитка — `/telescope-tile` | Ползунки широты от −90° до 90°, «Применить», карточки, счётчики лайков, «Подробнее». | Те же действия, плюс «Удалить» только на своих карточках. |
| Лента — `/telescope-feed` | Видео, описание, координаты, счётчик лайков, «Ещё» и переход к следующей карточке. | Дополнительно установка и отмена лайка. |
| Добавление — `/telescope-draft` | Пункт отключён; прямой переход ведёт на вход. | Загрузка своего черновика. Если его нет — название, файлы изображения и видео, предпросмотр и «Далее». После создания — описание, широта, долгота, «Опубликовать» и «Удалить». Название и загруженные файлы на этой стадии не изменяются, поскольку API не предоставляет их редактирования. |
| Вход — `/login` | Логин, пароль и кнопка «Войти». | В меню вместо «Вход» отображается «Выход», в шапке — логин. |

В карточках и предпросмотре используются локальные изображение и видео по умолчанию, если поле пустое или медиа не загрузилось. При публикации карточка переходит в опубликованные, после чего открывается плитка. Удаление логическое и выполняется сервером.

## Redux Toolkit и запросы

- `src/store.ts` — `configureStore` с middleware redux-thunk по умолчанию и поддержкой Redux DevTools.
- `src/slices/telescopesSlice.ts` — значения ползунков, применённый фильтр, каталог, лента, ошибки и `createAsyncThunk` для чтения, удаления и лайков.
- `src/slices/draftSlice.ts` — поля черновика и `createAsyncThunk` для получения, создания и публикации.
- `src/slices/userSlice.ts` — состояние гостя/пользователя, логин, токен, загрузка и ошибки входа.
- `src/slices/uiSlice.ts` — учёт выполняющихся thunk-запросов. Во время запросов появляется общий Spinner, действия и навигация блокируются.
- `src/components/LatitudeFilter.tsx` получает значения и обработчики через props. Фильтр сохраняется при переходах между страницами; его границы передаются в API как `min` и `max`. При выходе фильтр и пользовательские данные очищаются.
- Вход и выход выполняются **вручную через Axios в компонентах**, без сгенерированных методов и без thunk. Состояние Redux обновляется обычными actions.

## JWT

После успешного входа токен, логин и время истечения сохраняются в Redux и в `localStorage` под ключом `telescopes.session`. Пароль не сохраняется. Запросы телескопов получают заголовок `Authorization: Bearer <токен>` через Axios interceptor.

После обновления страницы по F5 Redux начинает с гостевого состояния: вход из `localStorage` автоматически не восстанавливается, сохранённый токен в гостевые запросы не добавляется. Запись `telescopes.session` остаётся в Application → Local Storage: значение `token` можно скопировать для запроса через Insomnia или Postman. Обновление страницы не вызывает серверный logout и не отзывает JWT.

Выход вызывает `POST /api/users/logout` и после подтверждения очищает локальный токен, состояние карточек и фильтр. Если сервер уже отклонил токен с 401, приложение также возвращается в гостевой режим. При сетевой ошибке выхода состояние пользователя сохраняется, чтобы можно было повторить отзыв токена. Истечение локального срока токена завершает вход автоматически.

## Кодогенерация

`src/api/Api.ts` — сгенерированный Axios-клиент, вручную не редактируется. Все запросы домена телескопов выполняются через его методы, вызываемые из thunk. Файл `src/api/index.ts` настраивает общий экземпляр и interceptor; `src/modules/telescopesApi.ts` преобразует данные для интерфейса и реализует гостевой mock fallback.

При изменении Swagger запустить работающий бэкенд и выполнить:

```powershell
npm.cmd run generate-api
```

Скрипт `scripts/generate-api.mjs` читает `http://localhost:8000/swagger/doc.json` и генерирует `src/api/Api.ts`.

## Сборка

```powershell
npm.cmd run build
```

Команда проверяет TypeScript и создаёт `dist/`. Прокси Vite работает в режиме разработки; для размещения production-сборки маршруты `/api` и `/s3` нужно настроить на сервере, который раздаёт фронтенд.
